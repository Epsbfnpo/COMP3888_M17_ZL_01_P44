## User Stories

* **Content creator:** I want to record the different stages of creating a digital asset so that I can provide evidence of how the final work was produced.  
* **Client:** I want to view the provenance history of a digital media file so that I can understand where it came from and whether it has been modified.  
* **Reviewer or investigator:** I want to examine previous versions, metadata, signatures, and supporting evidence so that I can verify the authenticity of a digital asset.  
* **User working with different media formats:** I want the system to support different types of evidence for audio, images, video, 2D artwork, and 3D/VFX content.  
* **Photographer or videographer:** I want camera-related provenance information to be recorded so that the original source of an image or video can be verified.  
* **Illustrator or digital artist:** I want evidence from different tools and stages of my workflow to be connected so that the provenance of my work can still be demonstrated even when the creation process crosses multiple applications or media types.

## Methodology

This project utilizes a multi-phased approach, incorporating literature research, domain analysis, and comparative case studies to establish a robust provenance framework.

## Deliverables

1. **1\. Domain Investigation and Comparison:** An analysis of VFX/3D, music/audio, illustration/2D, text, and photography/videography, focusing on their provenance and evidence-chain characteristics.  
2. **2\. Requirements and User Stories:** A documented set of functional and user requirements based on the client's use case.  
3. **3\. Provenance Evidence Model:** A description of the types of evidence that can be collected for different media formats, including metadata, previous versions, digital signatures, storyboards, and camera-related information.  
4. **4\. Provenance Workflow or Prototype:** A prototype or workflow demonstrating how evidence can be collected, connected, and presented to users.  
5. **5\. Media Case Study:** A detailed example showing how the proposed approach works for the selected media domain, particularly for a challenging area such as illustration/2D or photography/videography.  
6. **6\. Testing and Evaluation:** An evaluation of how effectively the proposed solution can establish an evidence chain and support provenance verification.  
7. **7\. Final Project Documentation:** A final report describing the investigation, methodology, developed solution, findings, limitations, and possible future improvements.
