# Bundled DDEX schemas

This directory pins RIN 2.1 and ERN 4.3 schemas for offline validation. Import
locations were changed only from remote URLs to adjacent local files; copyright
and licence notices inside the XSD files are unchanged.

DDEX states that evaluation is covered by its Evaluation Licence and production
implementation/use requires an Implementation Licence. Confirm licensing before
deployment. Sources and checksums are recorded in `SOURCES.json`.
