- Exact derivation checks use only declared ranges and gains. Original-rate PCM is processed in approximately ten-second blocks with vectorised placement, gain/fade envelopes, alternating holdout statistics, Gram accumulation, coverage and cross-block local-mismatch state. Tests cover ranges beyond 60 seconds, repeated locations, source identifiability and local tampering.
- The shared streaming WAV reader supports 8/16/24/32-bit integer PCM, 32/64-bit IEEE float, and both corresponding `WAVE_FORMAT_EXTENSIBLE` SubFormats. Decoding produces C-contiguous `(frames, channels)` NumPy `float32` arrays without whole-file reads. Tests cover signed 24-bit expansion, finite float values outside `[-1, 1]`, float64 conversion, EXTENSIBLE float, NaN/Infinity rejection, trailing-byte warnings, window seeking, ndarray caching and active-memory rejection.
- Complete-file proxies are generated in phase-aligned overlapping blocks with Kaiser-windowed sinc filtering. Tests cover a cached 48 kHz to 2000 Hz stereo proxy across the ten-second block boundary, non-integer 2100 Hz to 400 Hz anti-alias filtering, and full-file excerpt discovery at 65 seconds.

Estimated parameters remain diagnostic and do not rewrite graph claims, count as exact provenance proof, or override exact declared contradictions.
- Resource guards include a 128 MiB active-window limit, 256 MiB proxy-cache limit, weighted request work limit and the caller's requested wall-clock timeout (no evaluator-side 60-second cap). Tests confirm that an incomplete budget-limited search returns `unavailable` with `resource_budget_exhausted` and never `contradicted`, that an expired deadline degrades audio checks instead of timing out, and that the worker receives its deadline before the timeout.
