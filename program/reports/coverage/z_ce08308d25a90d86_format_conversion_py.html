1"""Declared format conversions: the same audio stored in another file format. 

2 

3A ``derived_from`` edge with ``transformation: "format_conversion"`` claims 

4that only the file format changed (for example a WAV take saved as FLAC, or a 

5WAV master encoded as MP3). The claim is checked against both files: sample 

6rate, channels, bit depth between lossless files, and length. These checks 

7compare a declaration with measured properties, so they are scored in 

8declaration consistency like other relationship claims. Between lossless 

9integer files the decoded samples are also compared exactly; that result is 

10report-only, because identical samples describe the content, not its origin. 

11"""
