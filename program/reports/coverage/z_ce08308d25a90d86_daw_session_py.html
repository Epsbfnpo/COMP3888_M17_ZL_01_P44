1"""Ableton Live sessions (.als) as production evidence. 

2 

3An .als file is gzip-compressed XML listing the tempo, time signature, tracks 

4and every audio clip's sample (file name, original file size, length in 

5samples and sample rate). It is written by the submitter's own software, so 

6its checks are ``submitter_document`` tier: they reveal contradictions with 

7the submitted graph and MIDI, but never release an Integrity value alone. 

8 

9A sample reference is matched to a submitted WAV by exact file size, frame 

10count and sample rate, not by name: names are free text, those three are 

11properties of the bytes. 

12"""
